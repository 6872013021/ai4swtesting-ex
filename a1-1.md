## 1. Test assumptions

Assume the file upload feature supports:

- Uploading files through a file picker.
- Multiple file uploads.
- File type validation.
- File size restrictions.
- Upload progress and success/failure notifications.

Example constraints (adjustable):

- Maximum file size: 10 MB.
- Allowed formats: PDF, JPG, PNG, DOCX.

## 8. Recommended test techniques

- Equivalence Partitioning: Valid and invalid file formats.
- Boundary Value Analysis: File size limits and maximum file count.
- Decision Table Testing: Combinations of file type, size, authentication, and upload permissions.
- Negative Testing: Invalid, corrupted, and malicious files.
- Security Testing: MIME spoofing, path traversal, and unauthorized access.
