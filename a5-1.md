### Test Ideas – Password Validation

| ID   | Test idea                                                                                                   | Risk / Expected result                                                    |
| ---- | ----------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| F-01 | Enter a password containing exactly 8 characters, at least one digit, and one uppercase letter.             | Verify that the minimum valid password length is accepted.                |
| F-02 | Enter a password containing exactly 20 characters, at least one digit, and one uppercase letter.            | Verify that the maximum valid password length is accepted.                |
| F-03 | Enter a password containing fewer than 8 characters, even when it includes a digit and an uppercase letter. | Verify that passwords shorter than 8 characters are rejected.             |
| F-04 | Enter a password containing more than 20 characters, even when it includes a digit and an uppercase letter. | Verify that passwords longer than 20 characters are rejected.             |
| F-05 | Enter a password within the valid length range that contains no digits.                                     | Verify that passwords without at least one digit are rejected.            |
| F-06 | Enter a password within the valid length range that contains no uppercase letters.                          | Verify that passwords without at least one uppercase letter are rejected. |
